# 笔记库规范

## 规则：用户说"创建笔记"或"记录一下"时

1. **统一存放**：所有笔记创建到 `~/Opensource/notes/` 目录下，不创建子目录
2. **先查重**：创建前先读 `~/Opensource/notes/_index.md`，确认是否已有相关笔记（有则更新，不重复创建）
3. **用模板**：创建前先读 `~/Opensource/notes/_template.md`
4. **创建后**：必须更新 `~/Opensource/notes/_index.md`，补充新笔记的索引行

## 笔记命名规范

格式：`主题描述.md`，使用中文，简洁清晰
- 好：`Claude-Code深度学习指南.md`、`OpenClaw多Key轮换与模型回退能力详解.md`
- 避免：`笔记1.md`、`temp.md`、`new.md`

## 笔记内部结构规范

每篇笔记必须包含：

```
---
topic: 主题名（简短）
date: YYYY-MM-DD
tools: 适用工具（如 Claude Code / OpenClaw / 通用）
summary: 一句话摘要，供索引使用
---

# 标题

> 一句话摘要（与 frontmatter summary 保持一致）

正文（标题层级不超过 3 级，## 和 ###）

## 关键结论

- 结论1
- 结论2
```

**关键结论**部分是给 AI 快速提取要点用的，必须存在，放在笔记末尾。

## 内容质量要求

- 摘要要能让 AI 仅凭一句话判断这篇笔记是否与当前任务相关
- 关键结论要精炼，每条独立成立，不依赖上下文
- 避免口语化叙述，用结论性语句
